JAAF入力の手伝い：エントリー下書きの選手を、JAAFの画面でチェックするだけ

📒 記録（エントリー下書き）にもどる

🔒 本郷中学校・高等学校 陸上競技部の先生が使うために作ったページです。どなたでも使えますが、エントリーの確定は必ずご自身で行ってください。

JAAFのエントリー画面で、種目のチェックを手伝います

レーンちゃんはじめまして、レーンちゃんです！ JAAFの申し込み画面で、選手ごとの種目にチェックを入れるところだけを手伝うよ。最後の確認と確定は、先生が自分でしてね。

🛡できること・しないこと

✅ することLANE NOTE で作ったエントリー下書きを見て、JAAFの画面の種目のチェック欄にチェックを入れるだけです。
🚫 しないこと「送信」「一時保存」「記録入力に進む」「確定」などのボタンは絶対に押しません。連絡先などの入力欄にもさわりません。
📋 記録はJAAFのもの画面に出る記録や登録の情報は、JAAFのデータのままです。LANE NOTE から記録を書きこむことはありません。
👀 最後は必ず本人チェックが合っているか、確認ページの中身、確定は、必ず先生ご本人が確かめて押してください（JAAFの利用のきまりでも、申し込みは本人の責任です）。

🧰準備するもの

  • パソコンのブラウザ（Chrome・Edge など）。ブックマークバーを使うので、スマホではできません。
  • LANE NOTE の記録のページの 🪪 選手台帳に、選手の登録番号（JAAFの会員番号）が入っていること。番号で選手を見つけるので、入っていると確実です。
  • LANE NOTE の「📝 エントリー下書き」で、その大会の選手と種目を選んであること。
  • JAAFに自分のアカウントでログインできること。

1下書きを作って「🟦 JAAF用にコピー」を押す

  1. LANE NOTE の記録のページで「📝 エントリー下書き」を開き、大会と選手・種目を選びます。
  2. 下の方の「🟦 JAAF用にコピー」を押します。下書きの中身がクリップボードにコピーされます（画面には出ません）。
  3. 「登録番号がない人」の名前が出たら、🪪 選手台帳で番号を入れてから、もう一度押すと確実です。

2「🟦 LANE→JAAF」をブックマークバーに入れる（最初の1回だけ）

下の青いボタンを、マウスでつかんで（ドラッグして）、ブラウザの上にあるブックマークバーまで運んで離します。

🟦 LANE→JAAFブックマークバーが見えないときは Ctrl+Shift+B（Macは ⌘+Shift+B）で出ます。
レーンちゃんこのページでボタンを押しても、何も起きないよ。JAAFの画面で、ブックマークバーから押すボタンなんだ。パソコンのブラウザの機能なので、スマホではできないよ。

3JAAFのエントリー画面で、ブックマークを押す

  1. JAAFに自分でログインして、大会の「申込む」から種目ごとに選手が並ぶ画面を開きます。
  2. ブックマークバーの「🟦 LANE→JAAF」を押します。
  3. クリップボードを読む許可を聞かれたら「許可」。読めないときは貼り付け欄が出るので、Ctrl+V で貼って「チェックを入れる」を押します。
  4. 右上にまとめが出ます。緑の線登録番号で一致 赤の線名前だけで一致（同じ人か必ず確かめる）

1人2種目（リレーは数えない）をこえるチェックは入れません。グレーの行（ほかでエントリー済み・対象外）も飛ばします。

4全部自分で確かめてから、自分で確定する

  1. チェックを1つずつ目で確かめます。まとめの「種目なし」「選手なし」「飛ばした」に出た人は、手で入れてください。
  2. 自分で「出場選手の記録入力に進む」を押し、次の画面も自分で入れます。
  3. 確認ページで、選手・種目・記録をすべて見てから、確定は先生ご本人が押します。

🆘困ったとき

「JAAFの大会エントリーの画面で押してください」と出る
種目ごとに選手が並ぶ画面ではありません。大会の「申込む」から、その画面を開いてから押してください。
「『JAAF用にコピー』の中身ではありません」と出る
クリップボードに別のものが入っています。LANE NOTE で「🟦 JAAF用にコピー」をもう一度押してから、すぐにJAAFの画面で押してください。
「クリップボードを読めませんでした」と出る
出てきた貼り付け欄に Ctrl+V で貼って「チェックを入れる」を押してください。
赤の線の人がいる
登録番号で見つからず、名前だけで一致した人です。同じ名前の別の人のこともあるので、必ず確かめてください。🪪 選手台帳に番号を入れると緑（番号で一致）になります。
ブックマークを押しても何も起きない
JAAFの画面が変わると動かないことがあります。その場合は、いつもどおり手で入れてください。

❓よくある質問

勝手に申し込まれてしまうことはありますか？
ありません。チェックを入れるだけで、送信・一時保存・確定などのボタンは押しません。
選手の情報はどこかに送られますか？
送りません。下書きの中身はクリップボードを通るだけで、LANE NOTE にもほかの場所にも送りません。JAAFの画面の中身も読み取るだけで、外へは出しません。
スマホで使えますか？
使えません。パソコンのブラウザのブックマークバーを使う機能です。
ほかの学校の先生に教えてもいいですか？
はい、どなたでも使えます。ただし、エントリーの確定は必ずご自身で行ってください。

# LANE NOTE バックアップ・復元・自動削除の手順書（v0.26.9）

この文書は管理者（阪田）向けです。有料機能はこの版では**有効にしていません**。

## 1. 守っているもの・守っていないもの

| データ | 置き場所 | 失われる場面 |
|---|---|---|
| 自分だけの記録 | 端末（IndexedDB）＋ログイン時は Firestore `users/{uid}` | 端末の削除・Firestore の誤削除 |
| チームの記録 | Firestore `teams/{tid}/records`（変更履歴 `hist` つき） | メンバーの誤操作（履歴から戻せる）・プロジェクトの事故 |
| 共有リンク・やり取り | `shares`・`talks`（期限つき） | 期限で消えるのが正しい動き |

## 2. 自動のバックアップ（Firestore の定期エクスポート）— **Blaze（従量課金）が必要**

Firestore の「スケジュールされたバックアップ」や `gcloud firestore export` は、Cloud Storage のバケットが必要で、**Blaze プランへの切り替え（クレジットカード登録）**が前提です。この版では行っていません。必要になったら、次を決めてから行ってください。

1. Firebase コンソール → プランを Blaze に変更し、**予算アラート（例：月100円）**を必ず設定する。
2. Firestore → 「障害復旧」→ バックアップのスケジュール（毎日・保持7日 など）を作る。
   - コマンドの例：`gcloud firestore backups schedules create --database='(default)' --recurrence=daily --retention=7d`
3. 復元は「新しいデータベースへ」行われます（`gcloud firestore databases restore ...`）。いまのデータベースは上書きされません。
4. 費用の目安：保存しているデータ量×日数に比例します（いまの規模なら少額）。

## 3. 無料でできる手動の備え（いまの運用）

- **顧問ひとりひとり**：記録の「💾 ファイルに書き出す（JSON）」で、学期ごとに手元へ保存する（表で見たいときは「📊 Excelに書き出す」も）。復元は書き出したファイルを読み込む。
- **管理者**：月に1回、Firebase コンソール → Firestore → データ で件数を確認する（急に減っていないか）。
- チームの記録の誤削除は、チーム画面の「変更履歴」→「この変更を取り消す」で戻せます（履歴は消えません）。
- サービスアカウントの鍵（JSON）は**作らない・どこにも貼らない**。エクスポートが必要なときはコンソールか、自分のGoogleアカウントでログインした `gcloud` を使う。

## 4. やり取りの自動削除（TTL）— 顧問がログインしなくても消える

選手とのやり取りのメッセージは、作るときに `purgeAt`（やり取りの期限と同じ日時）を必ず持つようにルールで決めています。Firestore の TTL（有効期限）ポリシーを設定すると、**期限を過ぎたものを Google 側が自動で削除**します（無料プランでも使えます。削除は期限から通常24時間以内、最大で数日かかることがあります）。

コンソールで1回だけ設定してください：

1. Firebase コンソール → Firestore → **TTL**（「Time-to-live」）→「ポリシーを作成」
2. 次の3つを作る：

| コレクショングループ | 日時のフィールド | 消えるもの |
|---|---|---|
| `msgs` | `purgeAt` | やり取りのメッセージ（体調メモを含む） |
| `talks` | `expiresAt` | やり取りの本体 |
| `shares` | `expiresAt` | 期限切れの共有リンク |

3. 状態が「提供中（Serving）」になれば完了。

注意：TTL は親の文書を消しても中のメッセージは消しません。そのため `msgs` の TTL（`purgeAt`）が必ず必要です。

## 5. 非常停止（v0.26.9）

- 管理者は記録帳の「チーム」欄の「🛑 機能の一時停止」から、やり取り・URL読み込み・利用カウンター・短いリンクの新規作成を全員について止められます。記録は止まりません。
- 管理者の印は、コンソール → Firestore → `admins` コレクション → 文書ID＝自分の uid（中身は `note: "管理者"` など何でもよい）を**手で作る**。アプリからは作れません。
- URL 読み込みの中継（Cloudflare Worker）は、Worker の環境変数 `RELAY_OFF` を `1` にすると、アプリの設定と関係なく止まります（再デプロイ不要）。

どちらで使いますか？

はじめに1回だけ選んでください。この端末に覚えます。あとで上の「モード」ボタンからいつでも切りかえられます。

🔒 選んだモードはこの端末だけに保存します（送信しません）。

📘 はじめての人はこちら（使い方ガイド）

まず触るなら ⏱ 3分体験 ・ 📄 印刷用の1枚の説明 LANE NOTE をはじめて使う人が、最初に読むページです。「🔰 使い方」を上から順に読むか、「📖 マニュアル」の「こんなときに使えます」から、やりたいことを選んでください。3分体験は架空のサンプルで、ログイン不要・保存しません。「印刷用の1枚の説明」は部内・保護者向けです。

1🏁 大会準備（エントリーした大会の当日資料づくり）

  1. スタートリスト（またはプログラム）とタイムテーブルのPDFを入れます。競技注意事項を入れると招集時刻のルールも自動で設定します（任意）。
  2. 学校・クラブ名を入れます。一部でOK（「第一」→ 第一高・第一中が出るので、必要な方にチェック）。
  3. 「時間順」「選手別」「記録用紙」「ナンバーカード」ができます。準決勝・決勝は「通過したら」の予定として入ります。
  4. 書類は「👀 画面で見る」「📄 PDF作成」「🖨 印刷」から選べます。

💡 「この端末に保存」を押すと、電波のない競技場でも開けます。

2📒 記録（自校の記録と自己ベストをためる）

  1. Googleでログインします（しなくても、この端末だけで使えます）。
  2. 学校・クラブ名を入れ、大会結果のPDF・保存したWebページ・Excel（.xlsx/.xls/.csv）を入れます。
  3. 確認画面で中身を見て「保存」。部内ランキング・歴代記録・選手ごとの自己ベストとグラフが見られます。
  4. 個人表・ランキング・歴代記録は「PDF作成」でA4のきれいな書類にできます。選手を選んで1人1ページにもできます。

💡 読み取りで漏れた記録は「✏️ 1件ずつ入力する」で足せます。

3🔗 選手ページ・個人ページ（選手に配るリンク）

  • 選手用リンク（予定）：大会準備の「スマホで見る／共有」から。その子の出場・招集時刻だけが入ります。
  • 個人ページ（記録）：記録ページの「📱 選手の個人ページを作る」から。別の画面で中学/高校・男女をしぼって選手にチェックを入れ、「🔗 チェックした人のリンクを作る」を押します。1人ずつの「コピー」か、「📋 まとめてコピー（LINE用）」で配れます。選手のページの「個人ページのリンク」からも1人分を作れます。
  • リンクにはその子の自己ベスト・推移グラフ・最近の記録だけが入ります（ほかの選手の記録は入りません）。選手はログインなしで見られます。
  • Googleでログイン中は短いリンク（作ってから119日まで・大会準備のページの「作った短いリンク」から止められます）、ログインなしは長いリンクになります。
  • 大会準備のページで同じ名前の選手用リンク（短いリンク）を作ってあれば、「大会当日の予定」へのリンクも入れます。
  • 個人ページは作った時点の写しです。新しい記録が入ったら作り直して配ってください。

4👤 個人で使う（選手本人・保護者・クラブの人）

記録ページの「👤 個人で使う」にチェックし、学校・クラブ名のかわりに自分の名前（と所属）を入れます。結果の資料から、その人の記録だけを取り込みます。同じ名前の別の人が混ざらないよう、所属も入れるのがおすすめです。

5🔐 ログインと保存場所

ログインする

記録はあなた専用のクラウド（Firebase）に保存。どの端末からでも同じ記録が見られます。ほかの人には見えません。

ログインしない

このブラウザの中（IndexedDB）にだけ保存します。ほかの端末からは見られません。

⚠ 共用のパソコンでは、使い終わったら必ずログアウトしてください。

6🔒 データの取り扱い（全文）

👥 「チームで共有」を使うと、チームの記録・変更履歴・メンバーの名前（Googleの表示名）が、そのチームの顧問・マネージャーに見えます。チームに入っていない人には見えません。

👀 作成者は、登録されたチームの名前（チーム名だけ）を見ることがあります。記録・メンバー・選手名は見ません。

📊 トップページ（記録のページ）は、利用回数だけを数えます。1台の端末につき1日1回、合計の回数を1増やすだけで、名前・端末・場所などの個人の情報は集めません。

記録のページ

🔒 Googleでログインすると、記録はあなた専用のクラウド（Firebase）に保存され、どの端末からでも見られます。ほかの人の記録は見えず、ほかの人からもあなたの記録は見えません。ログイン中も、電波がないときに見られるよう、この端末（IndexedDB）に控えを置きます（ログアウトすると控えを消します）。ログインしないときは、このブラウザの中（IndexedDB）にだけ保存します。ログインしていないときにためた記録は、ログインしても自動ではクラウドへ移しません（移すかどうかを件数を見て選べます）。結果資料・Excelの読み取りはすべてこの端末の中で行います（「URLから読み込む」を使ったときだけ、URLと取ってきた中身が LANE NOTE の Cloudflare 中継を通ります。中継は保存しません）。大会ごとの天気・気温と、中学/高校を選んだ選手の情報も、記録と同じ場所に保存します。「不具合・要望を送る」は Google でログインしたときだけ送れて、送った内容だけが作成者に届きます（記録や選手名は自動では送りません）。「個人で使う」（v0.8）の名前・所属は、記録と同じ場所（ログイン中は本人だけが読めるクラウドの設定、ログインなしはこのブラウザ）に保存します。「選手の個人ページ」のリンクには、その選手1人分の記録（自己ベスト・最近の記録・グラフの点）と名前・所属・学年だけを入れます。ログイン中は短いリンクとして LANE NOTE の Firebase（shares）に置き、リンクを知っている人なら誰でも作ってから119日まで見られます（大会準備のページの「作った短いリンク」から止められます）。ログインなしは長いリンクの「#」より後ろに入り、サーバーには送りません。選手がそのページで書く体調メモは、選手のスマホにだけ保存され、先生には見えません。「選手とのやり取り」（v0.24〜・先生がオンにしたときだけ）では、先生のひとことと選手・先生の返信だけを LANE NOTE の Firebase（talks）に置きます（v0.25 から体調メモは送れません）。読み書きできるのは、その選手専用のリンク（推測できない20文字）を知っている人（選手本人とは限りません）と先生だけです。作ってから119日まで・先生が停止するか全体をオフにすると読めません。先生が削除すると中身を消し、同じリンクは二度と使えません。期限が過ぎたものは、先生がやり取りの画面を開いたときに中身を消します。「顧問モード／選手モード」の選択と、選手モードにまとめたリンクの一覧は、この端末（localStorage）にだけ保存します。共用のパソコンでは、使い終わったら必ずログアウトしてください。

13💬 選手とのやり取り（使いたい先生だけ）

はじめはオフです。オフのあいだは、選手の画面にやり取りの欄は出ません。

14👥 チームで共有（顧問・マネージャーが同じ記録を使う）

同じ学校・クラブの先生やマネージャーが、それぞれ自分のGoogleアカウントでログインしたまま、同じチームの記録を見たり入れたりできます。アカウントやパスワードを貸し借りする必要はありません。

はじめかた

  1. 顧問の先生：「📒 記録」のページでGoogleログイン →「👥 チームで共有」→ チーム名を入れて「チームを作る」。
  2. 「🔑 参加コード」を開くと、顧問用とマネージャー用の2つのコードがあります。入ってほしい人にだけ、コピーして渡します（LINEのグループなど、だれでも見られる所には貼らないでください）。
  3. 入る人：自分のGoogleでログイン →「参加コードで入る」にコードを貼って「参加する」。コードははじめから「承認あり」なので、入る人は「承認待ち」になり、顧問が「👥 メンバー」で承認するとチームの記録が見えるようになります（承認なしにしたいときは、「詳しい設定」で外してコードを作り直します）。
  4. 入ったら、上の「保存先」でチームを選ぶと、チームの記録が出ます。「👤 自分だけ」を選ぶと、今までどおり自分だけの記録です。

できること（役割ごと）

  • 🧑‍🏫 顧問：すべて（記録の入力・修正、未確認の確認、メンバーの役割の変更・外す、参加コードの作り直し、持ち主の引き継ぎ）。選手とのやり取り・体調メモも顧問だけです。
  • 📋 マネージャー：記録・大会の天気などの入力と修正。チームの設定・参加コード・やり取り・体調メモは使えません。期限があり、はじめは年度末（3月31日）です。期限が来ると、自動でチームの記録を見られなくなります（顧問が期限をのばせます）。
  • 👟 選手：今までどおり、先生からもらった個人ページのリンクだけです（チームには入りません）。

こんなときに使えます

  • 大会の日に、マネージャーがスマホで結果を入れて、あとで顧問がまとめて確認したい。→ マネージャーが入れた記録には 未確認 の印が付きます。顧問が「確認済みにする」を押すと消えます。
  • だれかがまちがえて直してしまった。→「🕘 変更履歴」に、だれが・いつ・何をしたかが残ります。「この変更を取り消す」で元に戻せます（戻したことも履歴に残ります）。
  • 先生が異動する。→ 持ち主の先生が「🤝 引き継ぎ」で、ほかの顧問に持ち主を渡せます。
  • マネージャーが卒業・退部した。→ 顧問が「👥 メンバー」で「外す」を押すと、すぐに見られなくなります（コードも自動で作り直します）。外した人は、新しいコードでも入れません。もう一度入れるときは、「外した人」の欄で「再参加を許可」を押してから、新しいコードを渡してください。
  • 今まで自分だけで記録をためていた。→「📦 自分の記録をこのチームへコピー」で、確認してからチームにコピーできます。自分だけの記録は消えません。

🔒 だれが何をできるかは、画面だけでなく保存先（Firebase）のルールで決めています。チームに入っていない人、外された人、期限が過ぎたマネージャーは、チームの記録を読むことも書くこともできません。チームの記録はこの端末に控えを置かないので、電波がないときは見られません。

15📚 1年分の記録をまとめる（v0.26.50）

大会予定に入れてある終わった大会の結果を、公開されている結果の一覧からまとめてさがして、自分の学校の記録だけを一度に取り込みます。記録がまだ空っぽのときに便利です。

  1. 先に「📅 大会予定」に、大会名・日付（何日かある大会は終わりの日も）・競技場・中学/高校を入れておきます（CSV でまとめて入れられます）。記録のページで学校・クラブ名を入れます。
  2. 記録のページの「📚 1年分の記録をまとめる」を開き、期間（今年度・今年・この1年、または日付）を選んで「🔎 結果をさがす」を押します。大会予定のページの「📚 1年分の記録をまとめる」からも開けます。
  3. 大会ごとに、✔ 見つかった／❓ 候補を確認／✖ 見つからない／✅ 取り込み済み（○件）が出ます。「候補を確認」は、同じ日・同じ競技場に大会がいくつかあるときです。どれかを先生が選ぶまで読み込みません（「おすすめ」は、ほかの大会と同じ支部などの目安です）。
  4. 「📥 まとめて読む」で、大会ごとに結果を読み、自分の学校の行だけを下の確認画面に出します。大会名と日付は大会予定のものを使います。中学と高校で同じ日の同じ資料を使うときは、中学の予定には中学の選手、高校の予定には高校の選手だけを入れます。
  5. 確認画面で中身を見てから「💾 まとめて保存」を押します（保存の前にもう一度確かめます）。すでに保存してある同じ記録は重ねません。保存のあと、選手別（自己ベスト）・部内ランキング・大会別をすぐ見られます。
  • 見つからない大会（都外の大会・一覧にない大会など）は「📎 資料を入れる」から、PDF・Excel・URL を手で入れられます。その大会予定の名前と日付で読み取ります。
  • さがす先は、gold.jaic.org の東京陸協・高体連・中体連の一覧（今年度と前の年度の「過去の記録」）と、江東区陸協の結果のページです。みんなの結果に同じ大会があるときは候補に出しますが、自動では選びません。
  • 1年分（30大会ほど）で5分くらいが目安です（v0.26.51）。速報ページでは、各種目の最初のラウンド（予選・タイムレースなど）に自分の学校の選手がいないとき、その種目の決勝や総合結果は読みません。読み込み中は残り時間の目安が出て、大会を1つ読み終わるたびに、その大会の記録の件数・選手の数・自己ベスト更新が出ます。中継が混んでいるときは少し待ってから続けます。同じ画面で一度読んだページは読み直しません。スマホでは画面を開いたままにしてください。「やめる」でいつでも止められ、止めた分は保存しません。
  • 読み取りはこの端末の中で行います。結果のページは「URLから読み込む」と同じ LANE NOTE の Cloudflare 中継を通して取ってきます（中継は保存しません）。

💡 読み取りを間違えることもあります。保存する前に、元の結果と見比べてください。

16📝 エントリー下書き（v0.27.0）

記録ページの「📝 エントリー下書き」は、JAAFのエントリーシステムへ手で打ち込むときの下書きを作ります。送信や自動入力はしません。内容は保存しません（ページを閉じると消えます）。

  1. 男子・女子を選びます。
  2. 選手の種目ボタンを押して入れます。ボタンには公認ベストが出ます。公認記録が無ければ「公認記録なし（空欄でOK）」で、空欄のままで大丈夫です。

エントリーの前に、選手の希望を集めるリンクです。記録のページの「📝 エントリー下書き」の下にあります（Googleでログインした顧問だけ）。

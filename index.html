    ⚠ このリンクには選手名が含まれます。共有先に注意してください。

    🏃 選手用リンク（1人ずつ）

    選手それぞれに、その子の出場（種目・組・レーン・レースと招集の時刻）だけが入ったリンクとQRを作ります。ほかの選手の名前やリレーの仲間の名前は入りません。選手はログインなしで開けて、起きる時間などを自分で足せます（その子のスマホにだけ保存）。

    ⚠ リンクを知っている人なら誰でも、その子の名前と出場が見られます。LINEのグループに貼るときは、自分のリンクだけ開くよう伝えてください。

    使い方

    1. 大会のスタートリスト（またはプログラム）とタイムテーブル（競技時間）のPDFを、下の枠にドラッグするか、枠をクリックして選びます。競技注意事項も入れると招集時刻のルールを自動で設定します（任意）。
    2. 学校名を入れます（一部でOK。例：「本郷」→ 本郷高・本郷中が出るので、必要な方にチェック）。
    3. 「時間順」「選手別」「ナンバーカード」に結果が出ます。Excel保存・印刷・ナンバーカード（Word）作成ができます。
    ⚠ 試作版です。　本ツールはPDFの文字を読み取って自動で整理しているだけです。内容は必ず元のスタートリスト・タイムテーブル等と照らし合わせ、最終的には目で確認してください。本ツールの利用により生じた不利益について、作成者は責任を負いかねます。
    🔒 データの取り扱いについて（押すと開きます）
    • PDF本文はどこにも送りません。選手情報も、下の「短いリンク」を作ったときを除いてサーバーへ送信・保存しません。
    • 部品取得のため外部CDN（jsDelivr・SheetJS）へ通信します。プログラム部品（pdf.js・JSZip・SheetJS）は決まった版をハッシュ（SRI）で確認してから使い、確認できないブラウザでは読み込みません。pdf.jsが必要に応じて取りに行く文字の対応表（CMap）・標準フォントのデータはハッシュ確認の対象外です（プログラムではなくデータです）。短いリンクを作る・開くときだけ、Googleのサーバー（gstatic.com）から Firebase の部品を読み込みます。
    • 保存したファイル・印刷物は残ります。保存先のクラウド同期は各学校の設定によります。
    • 画面を閉じると、読み込んだ内容は消えます（「この端末に保存」を押したものだけ、その端末のブラウザに残ります。削除ボタンで消せます）。
    • 「スマホで見る／共有」でGoogleでログインしているときは短いリンク（…/?s=英数字10文字）を作ります。このとき、選んだ学校の結果（大会名・日付・時刻・選手名など）を LANE NOTE の Firebase（Google）に120日間保存し、リンクを知っている人なら誰でも見られます（一覧で探すことはできません）。
    • ログインしていないとき（または通信できないとき）は長いリンクになり、結果はリンクの「#」より後ろに入ります。この部分はサーバーへ送られず、どこにも保存されませんが、リンクを渡した相手は中身を見られます。
    • このページ（大会準備）の説明です。別ページの「記録」は、Googleでログインしたときだけ記録を LANE NOTE の Firebase（Google）に本人だけが読める形で保存します（ログインしないときはそのブラウザの中だけ）。
    • 選手用リンク（v0.11）：1人分の出場（大会名・日付・会場・種目・組・レーン・レースと招集の時刻・招集場所・その子の名前／学年／学校／ナンバー）だけを入れます。ほかの選手の名前・ナンバー（リレーの仲間も）は入れません。ログイン中は上と同じく Firebase に120日間保存（1人1件）、ログインなしは長いリンクの「#」より後ろに入ります。選手が自分で足した予定（起床など）と、開いたリンクの中身は、その選手の端末のブラウザにだけ保存し、どこにも送りません。
    • 不具合・要望を送る（v0.13）：フォームから送った内容は LANE NOTE の Firebase（Google）の feedback に保存し、作成者だけが確認します（送った人を含め、ほかの人は読めません）。送るのは 種類・内容・連絡先（書いたときだけ）・ページ名・版・ブラウザの種類・画面の大きさ・開いていたタブとURLのパス（「#」「?」より後ろは送りません）・ログイン中ならそのアカウントのID です。PDFの中身・選手名・記録は自動では送りません（内容に書いたものは送られます）。
    • 「ナンバーカード」タブのAmazonへのリンクは、押したときだけAmazonのページを開きます。自動で何かを送ったり、Amazonから画像などを読み込んだりはしません。

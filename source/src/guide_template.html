1🏁 大会準備（エントリーした大会の当日資料づくり）

  1. スタートリスト（またはプログラム）とタイムテーブルのPDFを入れます。競技注意事項を入れると招集時刻のルールも自動で設定します（任意）。
  2. 学校名を入れます。一部でOK（「本郷」→ 本郷高・本郷中が出るので、必要な方にチェック）。
  3. 「時間順」「選手別」「記録用紙」「ナンバーカード」ができます。準決勝・決勝は「通過したら」の予定として入ります。
  4. 書類は「👀 画面で見る」「📄 PDF作成」「🖨 印刷」から選べます。

💡 「この端末に保存」を押すと、電波のない競技場でも開けます。

2📒 記録（自校の記録と自己ベストをためる）

  1. Googleでログインします（しなくても、この端末だけで使えます）。
  2. 学校名を入れ、大会結果のPDF・保存したWebページ・Excel（.xlsx/.xls/.csv）を入れます。
  3. 確認画面で中身を見て「保存」。部内ランキング・歴代記録・選手ごとの自己ベストとグラフが見られます。
  4. 個人表・ランキング・歴代記録は「PDF作成」でA4のきれいな書類にできます。選手を選んで1人1ページにもできます。

💡 読み取りで漏れた記録は「✏️ 1件ずつ入力する」で足せます。

3🔗 選手ページ・個人ページ（選手に配るリンク）

  • 選手用リンク（予定）：大会準備の「スマホで見る／共有」から。その子の出場・招集時刻だけが入ります。
  • 個人ページ（記録）：記録ページの「📱 選手の個人ページを作る」から。別の画面で中学/高校・男女をしぼって選手にチェックを入れ、「🔗 チェックした人のリンクを作る」を押します。1人ずつの「コピー」か、「📋 まとめてコピー（LINE用）」で配れます。選手のページの「個人ページのリンク」からも1人分を作れます。
  • リンクにはその子の自己ベスト・推移グラフ・最近の記録だけが入ります（ほかの選手の記録は入りません）。選手はログインなしで見られます。
  • Googleでログイン中は短いリンク（作ってから119日まで・大会準備のページの「作った短いリンク」から止められます）、ログインなしは長いリンクになります。
  • 大会準備のページで同じ名前の選手用リンク（短いリンク）を作ってあれば、「大会当日の予定」へのリンクも入れます。
  • 個人ページは作った時点の写しです。新しい記録が入ったら作り直して配ってください。

4👤 個人で使う（選手本人・保護者・クラブの人）

記録ページの「👤 個人で使う」にチェックし、学校名のかわりに自分の名前（と所属）を入れます。結果の資料から、その人の記録だけを取り込みます。同じ名前の別の人が混ざらないよう、所属も入れるのがおすすめです。

5🔐 ログインと保存場所

ログインする

記録はあなた専用のクラウド（Firebase）に保存。どの端末からでも同じ記録が見られます。ほかの人には見えません。

ログインしない

このブラウザの中（IndexedDB）にだけ保存します。ほかの端末からは見られません。

⚠ 共用のパソコンでは、使い終わったら必ずログアウトしてください。

6🔒 データの取り扱い（全文）

記録のページ

🔒 Googleでログインすると、記録はあなた専用のクラウド（Firebase）に保存され、どの端末からでも見られます。ほかの人の記録は見えず、ほかの人からもあなたの記録は見えません。ログイン中も、電波がないときに見られるよう、この端末（IndexedDB）に控えを置きます（ログアウトすると控えを消します）。ログインしないときは、このブラウザの中（IndexedDB）にだけ保存します。ログインしていないときにためた記録は、ログインしても自動ではクラウドへ移しません（移すかどうかを件数を見て選べます）。結果資料・Excelの読み取りはすべてこの端末の中で行います（「URLから読み込む」を使ったときだけ、URLと取ってきた中身が LANE NOTE の Cloudflare 中継を通ります。中継は保存しません）。大会ごとの天気・気温と、中学/高校を選んだ選手の情報も、記録と同じ場所に保存します。「不具合・要望を送る」は Google でログインしたときだけ送れて、送った内容だけが作成者に届きます（記録や選手名は自動では送りません）。「個人で使う」（v0.8）の名前・所属は、記録と同じ場所（ログイン中は本人だけが読めるクラウドの設定、ログインなしはこのブラウザ）に保存します。「選手の個人ページ」のリンクには、その選手1人分の記録（自己ベスト・最近の記録・グラフの点）と名前・所属・学年だけを入れます。ログイン中は短いリンクとして LANE NOTE の Firebase（shares）に置き、リンクを知っている人なら誰でも作ってから119日まで見られます（大会準備のページの「作った短いリンク」から止められます）。ログインなしは長いリンクの「#」より後ろに入り、サーバーには送りません。選手がそのページで書く体調メモは、選手のスマホにだけ保存され、先生には見えません。共用のパソコンでは、使い終わったら必ずログアウトしてください。

大会準備のページ

  • （v0.22.2）読み込んだPDFの読み取り結果・学校名・設定は、再読み込みや「戻る」で消えないよう、このタブの中（sessionStorage）にだけ控えます。タブを閉じる・「最初から」・ログアウトで消えます。サーバーへは送りません。
  • PDF本文はどこにも送りません。選手情報も、下の「短いリンク」を作ったときを除いてサーバーへ送信・保存しません。
  • 「URLから読み込む」（v0.20）を使ったときだけは、ブラウザから直接ほかのサイトのファイルを取れない仕組みのため、入れたURLと取ってきた中身（PDF・Webページ）が LANE NOTE の中継（Cloudflare Workers）を通ります。中継は取ってきたものをそのままこの端末に渡すだけで、中身もURLも保存しません（Cloudflare の仕組みとして、通信の記録が一時的に残ることがあります）。読み取りはファイルを入れたときと同じく、この端末の中で行います。ログインが必要なページは読み込めません。（記録・エントリー照合のページでも同じです）
  • 部品取得のため外部CDN（jsDelivr・SheetJS）へ通信します。プログラム部品（pdf.js・JSZip・SheetJS）は決まった版をハッシュ（SRI）で確認してから使い、確認できないブラウザでは読み込みません。pdf.jsが必要に応じて取りに行く文字の対応表（CMap）・標準フォントのデータはハッシュ確認の対象外です（プログラムではなくデータです）。短いリンクを作る・開くとき・ログインするとき・不具合を送るときは、Googleのサーバー（gstatic.com）から Firebase の部品を読み込みます。Firebase の部品は版を固定していますが、ハッシュ確認はしていません（読み込み方の都合。今後、同じサイトから配る形に変える予定です）。
  • ログアウト（v0.14）：このページでログアウトすると、この端末に残っている「記録」ページの控え（ログイン中の記録のコピー）も消します。
  • 保存したファイル・印刷物は残ります。保存先のクラウド同期は各学校の設定によります。
  • 画面を閉じると、読み込んだ内容は消えます（「この端末に保存」を押したものだけ、その端末のブラウザに残ります。削除ボタンで消せます）。
  • 「スマホで見る／共有」でGoogleでログインしているときは短いリンク（…/?s=英数字10文字）を作ります。このとき、選んだ学校の結果（大会名・日付・時刻・選手名など）を LANE NOTE の Firebase（Google）に保存し、リンクを知っている人なら誰でも見られます（一覧で探すことはできません）。見られるのは作ってから119日まで（サーバーのルールで最長120日に制限。期限を過ぎると開けなくなりますが、データの自動削除はまだしていません）。「作った短いリンク」からいつでも共有を止められ、止めるとサーバーの中身も消えます。ただし、受け取った人が「この端末に保存」したコピー・長いリンク・スクリーンショットは、共有を止めても回収できません（短いリンクから保存したコピーは、電波のあるところで開いたときに消えます。期限を過ぎたものは開けません）。リンクには作った人を区別する番号（アカウントID）も入っています。
  • ログインしていないとき（または通信できないとき）は長いリンクになり、結果はリンクの「#」より後ろに入ります。この部分はサーバーへ送られず、どこにも保存されませんが、リンクを渡した相手は中身を見られます。
  • このページ（大会準備）の説明です。別ページの「記録」は、Googleでログインしたときだけ記録を LANE NOTE の Firebase（Google）に本人だけが読める形で保存します（ログインしないときはそのブラウザの中だけ）。
  • 選手用リンク（v0.11）：1人分の出場（大会名・日付・会場・種目・組・レーン・レースと招集の時刻・招集場所・その子の名前／学年／学校／ナンバー）だけを入れます。ほかの選手の名前・ナンバー（リレーの仲間も）は入れません。ログイン中は上と同じく Firebase に保存し、作ってから119日まで見られます（1人1件・止められます）、ログインなしは長いリンクの「#」より後ろに入ります。選手が自分で足した予定（起床など）と、開いたリンクの中身は、その選手の端末のブラウザにだけ保存し、どこにも送りません（選手のページの「この予定を端末から削除」で消せます。期限切れ・止めたリンクを開くと、端末の控えも消します）。
  • 通過したら出るラウンド（v0.16）：タイムテーブルにある準決勝・決勝などの時刻を、選手用リンクにも「通過したら」として入れます（その子の分だけ）。選手が押した「通過！」「敗退」は、その選手の端末のブラウザにだけ保存し、どこにも送りません。
  • 選手の個人ページ（v0.16）：「記録」ページで作るリンクです。その選手1人分の記録（種目ごとの自己ベスト・最近の記録・グラフの点・記録なしの大会）と名前・学校・学年だけを入れます（ほかの選手は入れません）。ログイン中は上と同じく Firebase の shares に保存し、作ってから119日まで見られます（止められます）。ログインなしは長いリンクの「#」より後ろに入ります。作った時点のコピーなので、あとで記録が増えても自動では変わりません。
  • 体調メモ（v0.16）：選手のページ（予定・個人ページ）で書く体調・睡眠時間・ひとことメモは、その選手のスマホのブラウザにだけ保存し、どこにも送りません。先生にも見えません（「この日のメモを削除」「体調メモを全部削除」で消せます）。
  • 不具合・要望を送る（v0.13・v0.14からGoogleでのログインが必要）：フォームから送った内容は LANE NOTE の Firebase（Google）の feedback に保存し、作成者だけが確認します（送った人を含め、ほかの人は読めません）。送るのは 種類・内容・連絡先（書いたときだけ）・ページ名・版・ブラウザの種類・画面の大きさ・開いていたタブとURLのパス（「#」「?」より後ろは送りません）・ログインしているアカウントのID です（メールアドレスは送りません）。PDFの中身・選手名・記録は自動では送りません（内容に書いたものは送られます）。

7🛑 共有と止め方

  • 短いリンク（ログイン中に作るリンク）は、作ってから119日まで見られます。
  • 大会準備のページの「作った短いリンク」から、いつでも共有を止められます。止めるとサーバーの中身も消えます。
  • 受け取った人が「この端末に保存」したコピー・長いリンク・スクリーンショットは、止めても回収できません。LINEのグループなどでは、自分のリンクだけ開くよう伝えてください。

8📝 体調メモ（選手のスマホだけ）

選手のページで、体調（5段階）・睡眠時間・ひとことを書けます。その選手のスマホにだけ保存し、どこにも送りません。先生にも見えません。「この日のメモを削除」「体調メモを全部削除」で消せます。

9❓ よくある質問

お金はかかりますか？

無料です。広告もありません。

読み取りを間違えることはありますか？

あります。読めなかったところは空欄にして警告を出します（推測で埋めません）。必ず元の資料と照らし合わせてください。

スマホでPDFにするには？

「📄 PDF作成」→ 印刷画面の保存先で「PDFに保存」を選びます。

機種を変えたら記録は？

Googleでログインしていれば、新しい端末でも同じ記録が見られます。ログインなしでためた記録は、ログイン後に件数を見てクラウドへ移せます。

不具合を見つけたら？

各ページの「📮 不具合・要望を送る」から送ってください（Googleでのログインが必要です）。

10✅ エントリー照合（出したエントリーと届いたスタートリストを比べる）

  1. 上の「✅ 照合」を開き、大会に出したエントリーファイル（Excel .xlsx／.xls・CSV）と、届いたスタートリストのPDFを入れます。
  2. 学校は、エントリーファイルの「所属」から自動で選びます（違えば学校名を入れ直してチェック）。
  3. 結果は、確かめてほしいものから順に出ます。⚠️ エントリーしたのにスタートリストにない／❓ スタートリストにだけある／✅ 両方ある。リレーはチームごとにメンバーを比べて、別に出します。
  4. 「👀 画面で見る」「📄 PDF作成」「🖨 印刷」で、1枚の表にできます。
  • 名前の空白・全角/半角・ひらがな/カタカナ・旧字（澤/沢、邊/邉/辺、髙/高、﨑/崎 など）の違いは「表記ゆれで一致」として印を付けます。
  • 種目は「中1_100」と「男子中学1年 100m」のような書き方の違いを、性別の列も使ってそろえます。
  • エントリーファイルの形は大会ごとに違うので、氏名（または姓・名）・フリガナ・学年・性別・所属・種目（種目1・2・3…）・リレーの列を自動で探します。合わないときは「🔧 列の割り当て」で選び直してください。

🔒 2つのファイルはこの端末の中だけで読み取り、どこにも送りません。画面を閉じると消えます。

11👪 保護者へのお知らせ

保護者へ配るお知らせ（大会名・日にち・競技場・集合・持ち物・注意事項・出場選手表・時間順の予定）を、A4 1枚の文書にします。AIは使いません。決めておいたひな形に、資料から見つけた値を入れるだけです。

  1. 大会準備のページでPDF（スタートリスト・タイムテーブル、あれば要項・注意事項）を入れて学校を選び、「👪 保護者へのお知らせ」を押します。
  2. はじめの1回だけ「⚙ 学校の設定（毎回同じ）」で、学校名・部活名・顧問名・宛先・タイトル・持ち物・注意事項・連絡先・レイアウトなどを決めて「💾 ひな形を保存」を押します（ログイン中はアカウントにも保存され、ほかの端末でも使えます）。
  3. 次の大会からは「📅 この大会だけ」を確かめるだけです。大会名・日にち・競技場・最寄り駅・開門は資料から入ります（どこから見つけたかが下に出ます。見つからないときは空のまま。推測はしません）。集合時刻は「自校の最初の種目／競技開始／開門の○時間○分前」、解散予定は「最後の種目の○分後」で計算します。どれも直せます。
  4. 「📄 PDF作成」「🖨 印刷」「📝 Wordで保存（.docx）」で仕上げます。表だけほしいときは「📋 …をコピー」「📊 表をExcelで保存」も使えます。
  • レイアウトは「スタンダード」（大会名の帯＋要点のカード）「カード」（欄ごとに枠で囲む・時刻を大きく）「ミニマル」（線だけのすっきりした形）の3つ。アクセントの色（紺・赤・緑・青緑・紫・黒）を選べます。白黒のプリンターなら「白黒印刷向け」をオンにしてください。
  • 「A4 1枚に収める」（はじめはオン）は、余白・行間・文字を自動で小さくして1枚に入れます。8ptまで小さくしても入らないときは、長い欄を知らせます。
  • 欄は表示を切ったり、↑↓で順番を変えたり、「＋欄」で自由欄を足したりできます。文の中の {大会名} {日付} {集合時刻} などは、その値に置きかわります。
  • 🏟 競技場の設定（大会準備の結果の上のボタン、またはお知らせの「⚙ 学校の設定」から）で、よく行く競技場を登録します。「＋ 競技場を追加」で名前（必須）・住所・最寄り駅・駅からの行き方・いつもの集合場所・交通費（経路・片道・往復・メモ）・メモを入れて「保存」。一覧のカードから「編集」「削除」できます。お知らせの「今回の競技場」で選ぶと、最寄り駅・集合場所・交通費が入ります。要項の競技場名と同じ（一部でも）ならはじめから選ばれます。未登録のときは「要項の競技場『…』は未登録です → 登録する」から、名前・住所・電話が入ったフォームを開けます。交通費は登録した金額だけを使います（運賃を調べたり推測したりはしません）。この大会だけ直した最寄り駅などは、登録した競技場には書き戻しません。
  • ← 戻る：お知らせ・競技場の設定・画面で見る・個人表などの全画面の画面は、上の「← 戻る」か、ブラウザ・スマホの「戻る」で閉じます（ページからは離れません）。読み込んだ内容はこのタブの中に控えてあるので、うっかり再読み込みしても戻ります。
  • 出場選手表は、はじめは出しません（「文書の中身」でオンにできます）。
  • 名前や種目の書き方はスタートリストのままです。配る前に、必ず目で確かめてください。

👥 チームの設定

チームを作る・参加コードで入る、メンバーと役割、参加コード、引き継ぎ、見える人とリンクをここで扱います。📒 記録のページへ戻る

チームの設定は、顧問・マネージャーの方がGoogleでログインしてから使います（選手・保護者の方は使いません）。

📅 大会予定

これからの大会を登録して、あと何日・エントリー締切をカレンダーで見られます。登録した予定は、大会準備の「大会予定から選ぶ」と、選手に送るリンク（これからの大会）で使います。ログインしているときは記録と同じ保存先（自分のクラウド／チーム）に保存します。

1学校・クラブ名と結果の資料

🔒 ログインすると自分専用のクラウドに保存（ほかの人には見えません。「チームで共有」を使ったときだけ、そのチームのメンバーに見えます）。ログインなしはこの端末だけ。「URLから読み込む」のときは、URLと中身が LANE NOTE の中継を通ります（保存しません）。利用回数だけを数えます（個人の情報は集めません）。詳しくは はじめての人はこちら

ⓘ 記録は元資料と照らし合わせてください 結果の資料の文字を読み取って整理しているだけです。記録は必ず元の結果資料と照らし合わせて確認してください。読めなかったところは空欄にして警告を出します（推測で埋めません）。
「本郷」と打つと「本郷」「本郷高」「本郷中」を拾います。
📚 1年分の記録をまとめる大会予定の大会の結果を、まとめてさがして取り込みます。
📄 結果のファイルをここへ
PDF・Webページ（HTML）・Excel（.xlsx/.xls/.csv）・複数OK

結果のPDF・保存したWebページ（HTML）・Excel（.xlsx/.xls/.csv）を入れます。複数まとめて入れられます（種目ごとにページが分かれた結果サイトは、ページを全部保存して一度に入れてください）。

📋 Webページの結果を貼り付けるファイルにできないときに使います。

結果のページを開き、Ctrl+A（全部選ぶ）→ Ctrl+C（コピー）して、ここに貼り付けます。種目ごとにページが分かれているときは、続けて貼り付けてかまいません。

URLだけを貼ったときは、上の「URLから読み込む」に入れます。

✏️ 1件ずつ入力する読み取りで漏れた記録・資料のない記録を入れます。

＊は必須です。氏名・所属・種目・大会名は、今までの記録から候補が出ます（氏名を選ぶと、フリガナ・学年・所属も入ります）。

📅 これからの大会は 大会予定 へ 今後の大会・カレンダー・まとめて追加・Google カレンダーからの読み込みは、大会予定のページで使います。

取り込み済みの大会
    ➕ 大会予定をまとめて追加CSV・Excel から貼り付け・Google カレンダー

    CSV（Excel なら「CSV UTF-8」で保存）を選ぶか、表を貼り付けてください。1行目は 大会名,日付,終了日,会場,区分,締切。大会名と日付は必須、終了日（2日以上の大会）・会場・区分（中／高）・締切（エントリー締切）は空でかまいません。登録済みの大会はとばします。

    Google カレンダーから入れるCSV を作らずに入れられます

    ① パソコンで Google カレンダーを開き、左の「マイカレンダー」で大会を入れているカレンダーの「︙」→「設定と共有」。
    ② 下の方の「カレンダーの統合」にある 「iCal 形式の公開URL」（カレンダーを公開しているとき）か 「iCal 形式の非公開URL」 をコピーして、下に貼ります。
    ・非公開URLを知っている人は、そのカレンダーの予定をすべて見られます。人に送ったり、ほかの所に貼ったりしないでください（LANE NOTE はアドレスを保存しません。読み込みは LANE NOTE の中継を通ります）。
    ・アドレスを使いたくないときは、「設定」→「インポート／エクスポート」→「エクスポート」で出したファイル（.zip の中の .ics）を、上の「CSV／.ics を選ぶ」で選んでも入ります。

    3データの持ち運び・消去

    ほかの消し方クラウドのデータすべて・この端末のデータ・共有の停止

    「この端末のデータを消す」は、このブラウザに残っている記録（ログインしていないときの記録と、ログイン中の控え）と、天気・中学/高校の選択を消します。ログイン中のクラウドの記録は消えません。短いリンク（共有）を止めるときは、大会準備のページの「スマホで見る／共有」→「作った短いリンク」から止められます。Googleのアカウント自体は消えません。

    書き出したファイルには選手の氏名と記録が入ります。学校のルールに従って保管してください。読み込むと、今ある記録に足し合わせます（同じ記録は重ねません）。

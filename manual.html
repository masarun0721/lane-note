レーンちゃんLANE NOTE は、陸上部の顧問の先生の「手で打つ仕事」を減らすための道具だよ。無料で、広告もないよ。大きく分けると 大会準備・照合・エントリー・記録 の4つ。順番に見ていこう！

🏁 大会準備（大会の前）

スタートリスト・タイムテーブルを読む

  • PDFを入れる（ファイルかURL）と、自分の学校の選手だけを探します
  • 「時間順」「選手別」の一覧にして、PDF・印刷・Excelに
  • 競技注意事項から招集時刻を読んで、一覧に入れます

当日に配るもの

  • 記録を書きこむ記録用紙（PBと前回の記録つき）
  • ナンバーカード（ゼッケン・腰番）の Word ファイル
  • 要項・注意事項から読んだ単価で参加料の合計

配る・知らせる

  • 「📱 スマホで見る／共有」でリンクとQRコード
  • 「🏃 選手用リンク」：選手1人ずつ、その子の出場と招集時刻だけ
  • 「👪 保護者へのお知らせ」（Word・PDF）

✅ 照合（エントリー漏れのチェック）

申し込んだエントリーの資料と、発表されたスタートリストを見くらべて、載っていない人・種目がちがう人を一覧にします。

📝 エントリー（大会の申し込みの前）

📮 エントリー調査リンク

  • 大会ごとに1つのリンクを LINE などで送るだけ
  • 選手はログインなしで、名前と第1・第2希望、リレーに出られるかを送れます
  • 答えた人・まだの人がひと目でわかります
  • 「📄 最終チェック用PDF」で、学年ごとの確認表を作れます

📝 エントリー下書き

  • 選手と種目を選ぶと、手で打ちこむときの下書き（公認ベスト・大会と日付つき）
  • 1人2種目まで などのルールの警告と、参加料の合計
  • 調査の答えを1回押すだけで入れられます

📅 大会予定

  • 今後の大会をカレンダーで
  • 要項から締切を読み、「エントリー済」「振込済」をチェック
  • CSV や Google カレンダーからまとめて入れられます

📒 記録（大会のあと）

結果を取り込む

  • 結果のPDF・Webページ・Excel・貼り付けた文章から、自分の学校の記録だけ
  • 「📚 1年分の記録をまとめる」で、終わった大会をまとめて
  • 「🔍 怪しい記録チェック」で二重や変な記録を探せます

見る・配る

  • 選手ごとの自己ベスト（PB）とグラフ、部内ランキング、歴代記録
  • 大会ごとの「大会まとめ」（PB更新の印つき）
  • 1人A4 1枚の「今年のふりかえりシート」

選手とつながる

  • 「📱 選手の個人ページ」：その子の記録とグラフだけのリンク
  • 「💬 選手とのやり取り」（はじめはオフ・使いたい先生だけ）
  • 「👥 チーム」で顧問・マネージャーと一緒に記録を入れられます

👤 顧問モードと選手モード

はじめに「顧問・コーチの方」か「選手・保護者の方」かを選びます。選手モードでは、もらったリンク・次の大会の予定・自己ベスト・体調メモが1つの画面にまとまります。

レーンちゃん全部を覚えなくて大丈夫！ 使いたい場面の記事だけ読めばOKだよ。

大会準備

大会の前日に、部員の時間表を配る

⏱ 読む時間：約4分 ／ 使うページ：🏁 大会準備

📑 目次
  1. 用意するもの
  2. 手順
  3. 選手に1人ずつ送りたいとき
  4. 記録用紙もいっしょに
レーンちゃん大会の前の夜に、スタートリストから自分の部員を探してマーカーを引く…。それ、もうやらなくていいよ！

用意するもの

  • 大会のスタートリストとタイムテーブル（PDF、または公開されているページのURL）
  • あれば競技注意事項（招集時刻を読むのに使います）

手順

  1. 上の「🏁 大会準備」を開きます。大会予定に入れてある大会なら「📅 大会予定から選ぶ」で大会名と日付が入ります。
  2. PDFをファイルで入れるか、「🔗 URLから読み込む」にアドレスを入れて「読み込む」を押します。
  3. 学校・クラブ名を入れます。
  4. 「時間順」の「👀 画面で見る」で、できあがりを確かめます。
  5. 「📄 PDF作成」か「🖨 印刷」で配ります。スマホで配るなら「📱 スマホで見る／共有」でリンクやQRコードを作ります。

選手に1人ずつ送りたいとき

「🏃 選手用リンクを作る」を押すと、選手1人ずつ、その子の出場と招集時刻だけが入ったリンクができます。準決勝・決勝など「通過したら」出るラウンドも入り、選手はリンクの中で「通過！」「敗退」を押せます。

記録用紙もいっしょに

「記録用紙」は、当日に記録を書きこむ表です。選手ごとにPB（これまでの公認ベスト）と前回大会の記録が入るので、その場で「ベスト更新！」がわかります。Excel でも保存できます。

⚠ ここは必ず見てね招集時刻が注意事項から読めなかったときは、勝手に決めずに空欄にして「⚠ 招集時刻を読めませんでした」と出します。「⚙ 設定」で手で入れると計算します。配る前に、元の資料と見くらべてください。
💡 コツ「新しい大会を始める（全消去）」を押すと、前の大会のPDFと設定を消して、まっさらから始められます。

大会準備

保護者へのお知らせを、資料から作る

⏱ 読む時間：約3分 ／ 使うページ：🏁 大会準備

📑 目次
  1. 手順
  2. 競技場の情報は一度だけ
レーンちゃん毎回ほとんど同じ文なのに、日付と会場を打ちかえるのって大変だよね。ひな形を一度作れば、次からはほぼ自動だよ。

手順

  1. 大会準備のページで、いつものようにPDFを入れます。
  2. 「👪 保護者へのお知らせ」を押します。
  3. 学校の設定（学校名・顧問・持ち物・注意事項など）を入れます。一度入れれば、ひな形として次から使えます。
  4. レイアウトと色を選び、Word（.docx）か PDF で保存、または印刷します。

競技場の情報は一度だけ

最寄り駅や行き方、集合場所は「🏟 競技場の設定」に一度入れておくと、同じ競技場の大会では自動で入ります。

💡 コツ白黒で印刷する学校は「白黒印刷向け」に切りかえると、色がなくても読みやすくなります。

大会準備

ナンバーカードと参加料も、まとめて片づける

⏱ 読む時間：約2分 ／ 使うページ：🏁 大会準備

📑 目次
  1. ナンバーカード（ゼッケン・腰番）
  2. 参加料
レーンちゃんスタートリストを入れると、「ナンバーカード」と「参加料」のタブも使えるようになるよ。

ナンバーカード（ゼッケン・腰番）

出場する選手の番号で、ゼッケン（胸・背中）と腰番の Word ファイルを作ります。B5の用紙に「実際のサイズ（100%）」で印刷してください。ゼッケンは1ページに1枚、腰番は1ページに上下2枚（半分に切る）です。

⚠ フォントについてナンバーカードはパソコンに入っている「HGP創英角ｺﾞｼｯｸUB」「ＭＳ ゴシック」を使います。無いときは別のフォントで表示されます。印刷は Word から行ってください。

参加料

要項や注意事項から単価を読み取り、出場する種目の数から合計を出します。読み取れなかったときは「参加料を読み取れませんでした」と出るので、表に単価を入れてください。

レーンちゃん電卓とにらめっこする時間が減るね！

照合

エントリー漏れを、スタートリストで確かめる

⏱ 読む時間：約3分 ／ 使うページ：✅ 照合

レーンちゃんスタートリストが出たら、すぐにチェック！ 漏れがあれば、早いうちに大会の係に問い合わせできるよ。

手順

  1. 上の「✅ 照合」を開きます。
  2. エントリーした資料（申し込みのファイル）と、スタートリストを入れます。URLなら「読み込む」を押します。
  3. 「👀 画面で見る」で結果を確かめます。
  4. 必要なら「📄 PDF作成」「🖨 印刷」で残します。
⚠ 最後は目で照合は、ファイルの文字を読み取って自動で突き合わせているだけです。名前の書き方のちがいなどで、まちがうこともあります。最後は元の資料と見くらべてください。
レーンちゃん漏れがなければ、今日はもう安心して寝られるね…💤

エントリー

エントリーの前に、選手の希望をリンクで集める

⏱ 読む時間：約5分 ／ 使うページ：📒 記録 →「📝 エントリー下書き」

📑 目次
  1. 1. 調査リンクを作って送る
  2. 2. 選手が答える
  3. 3. 答えを下書きに入れる
  4. 4. 最終チェック用PDF
レーンちゃん「出たい種目を紙に書いて出して〜」を、リンク1本にしちゃおう。集計は LANE NOTE がやるよ。

1. 調査リンクを作って送る

  1. 記録のページの「📝 エントリー下書き」を開き、「📮 エントリー調査リンク」を押します（Googleでログインした顧問だけ使えます）。
  2. 大会・男女・名簿・種目・締切を選び、「📮 リンクを作る」を押します。公式戦なら「希望を聞く」、記録会なら「出る種目」を選びます。
  3. 「🔗 リンクをコピー」か「LINEで送る」、または「🔳 QR」で選手に知らせます。

2. 選手が答える

選手はログインなしでリンクを開き、自分の名前を選んで、第1・第2希望の種目、リレーに出られるか、ひとことを送ります。出場しない人は「出場しない」を選んで理由だけ送れます。

⚠ 知っておいてねリンクを知っている人はだれでも、名簿のどの名前でも送れます。おかしな答えがあったら、選手本人に確かめてください。

3. 答えを下書きに入れる

  1. 答えの一覧で、答えた人とまだの人を確かめます（「🔄 読み込み直す」で最新に）。
  2. 「📥 希望を下書きに入れる」を押すと、希望の種目がエントリー下書きに入ります。
  3. 下書きで種目を直します。手で直した選手には「手直し済」の印がつき、答えを入れ直しても上書きされません。

4. 最終チェック用PDF

「📄 最終チェック用PDF」で、学年ごとに名前順に並べた確認表（希望の種目に ☐ つき）を作れます。部員に回して、まちがいがないか見てもらうのに便利です。

💡 下書きでできること1人2種目まで・リレー2チームまでなどのルールの警告と、参加料の合計が出ます。「🖨 印刷・PDF」「📋 文字でコピー」で、手で打ちこむときの手元の資料にできます。下書きはどこにも送信しません。
レーンちゃん集計の時間がまるごと浮くよ。グッド！

大会予定

大会予定と締切を、1つのページで管理する

⏱ 読む時間：約3分 ／ 使うページ：📅 大会予定

📑 目次
  1. 大会予定を入れる
  2. 進み具合をチェックする
  3. そのまま大会準備へ
レーンちゃん「あれ、締切いつだっけ？」をなくそう！

大会予定を入れる

  • 1件ずつ入れる
  • CSV（ひな形をダウンロードできます）や、Excel から貼り付けた表でまとめて入れる
  • Google カレンダーの .ics ファイルや iCal の URL から入れる（大会らしい予定にははじめからチェックがつきます）

進み具合をチェックする

大会ごとに「エントリー済」「振込済」にチェックを入れられます。カードには「未エントリー（締切が近いと赤）」「準備OK」「結果取込済」などの印が出ます。要項を読み込んだ大会は、エントリー締切や振込締切も要項から読んで出します（読めないときは手で入れられます）。

そのまま大会準備へ

「📋 大会準備へ」から開くと、その大会の資料として保存され、あとから「続きから」開けます。

💡 みんなの要項ほかの学校の先生が同じ大会の要項を登録していれば、その情報を使えます（登録されるのは大会名・日付・会場・要項のURLと読み取った大会の情報だけで、選手の名前は登録しません）。

記録

結果を取り込んで、自己ベストを管理する

⏱ 読む時間：約5分 ／ 使うページ：📒 記録

📑 目次
  1. 取り込みの手順
  2. 見られるもの
  3. 1年分をまとめて、ふりかえり
  4. 記録のおそうじ
レーンちゃんExcel に1行ずつ打っていた記録、取り込みで一気に入れちゃおう！

取り込みの手順

  1. 上の「📒 記録」を開き、学校・クラブ名を入れます（個人で使うなら「👤 個人で使う方はこちら」）。
  2. 結果のPDF・Webページ・Excelを入れます。文章をコピーして「貼り付けた文章を読み取る」でもOKです。
  3. 確認の画面で自分の学校の記録を確かめて、保存します。
💡 Googleでログインすると記録が自分専用のクラウドに保存され、ほかの端末からも見られます。ログインしなくても、この端末だけで使えます。

見られるもの

  • ホーム：最新の大会の自己ベスト更新
  • 選手別：自己ベストと記録の推移グラフ・個人表
  • 部内ランキング・歴代記録
  • 大会まとめ：その大会の全員の結果（PBの印つき）。PDF・印刷・リンクで共有

1年分をまとめて、ふりかえり

「📚 1年分の記録をまとめる」で、大会予定に入れた終わった大会の結果をまとめて探して取り込めます。そのあと「📝 ふりかえりシートを作る」で、選手1人A4 1枚の「今年のふりかえり」（種目ごとのベスト・自己ベスト更新・推移グラフ・先生から一言の枠）を作れます。

記録のおそうじ

データ

データの保存と書き出し・引っ越し

⏱ 読む時間：約4分 ／ 使うページ：📒 記録

📑 目次
  1. どこに保存される？
  2. 控えを取る（書き出し）
  3. 別の端末へ移す（読み込み）
  4. 古いアドレスからの引っ越し

どこに保存される？

  • ログインしていないとき：この端末のブラウザの中だけ。ほかの端末からは見えません。ブラウザのデータを消すと消えます。
  • Googleでログインしたとき：自分専用のクラウドに保存され、ほかの端末からも同じ記録を見られます。

控えを取る（書き出し）

  1. 「📒 記録」を開きます。
  2. 「💾 ファイルに書き出す（JSON）」を押すと、記録を全部1つのファイルにして保存します。
  3. 表で見たいときは「📊 Excelに書き出す」。

別の端末へ移す（読み込み）

移したい端末で「📒 記録」を開き、「📂 ファイルから読み込む」で書き出したファイルを選びます。

古いアドレスからの引っ越し

LANE NOTE は lane-note.web.app に引っ越しました。古いアドレスで開くとお知らせが出ます。古いアドレスの端末に記録が残っているときは、お知らせの「記録を書き出す」でファイルにして、新しいアドレスで「📂 ファイルから読み込む」をしてください（保存場所はアドレスごとに別なので、自動では移りません）。

⚠ ファイルの扱い書き出したファイルには選手の氏名と記録が入ります。学校のきまりに従って、大切に扱ってください。

大会予定

要項から締切・申込方法を読む

⏱ 読む時間：約3分 ／ 使うページ：📅 大会予定・🏁 大会準備

手順

  1. 「📅 大会予定」で大会の「📋 大会準備へ」を押し、その大会の要項（PDFかURL）を読み込みます。
  2. 要項の中の「申込」「参加料の振込」「申込書」などの言葉と日付を探して、大会予定の「エントリー済」「振込済」のチェックの横に締切を出します。「エントリーの出し方」も要項から読めたときは自動で入ります（手で選び直せます）。

⚠ 最後は要項で確かめて要項の書き方は大会ごとにちがうので、読みまちがえることがあります。申し込みの前に、必ず元の要項を見てください。

エントリー

調査で「別の端末」警告が出たとき

⏱ 読む時間：約2分 ／ 使うページ：📝 エントリー下書き

📑 目次
  1. どういう意味？
  2. よくある理由
  3. どうすればいい？

どういう意味？

選手が答えを送ると、送った端末ごとの印（ランダムな文字。名前などは入りません）が一緒に保存されます。最初に送った端末とちがう端末から答えが書きかえられたとき、顧問の答えの画面に「⚠ 別の端末から書きかえられた答えがあります」と出て、その人の行に「⚠ 別の端末」の印がつきます。

よくある理由

  • 本人がスマホを替えた・家のパソコンから送り直した
  • 友だちのスマホを借りて送った
  • まれに、ほかの人のいたずら

どうすればいい？

止めはしないので、そのまま下書きに入れることもできます。入れる前に、本人に「この希望で合ってる？」と確かめてください。ちがっていたら、本人にもう一度送ってもらうか、下書きで手で直します。

困ったとき

トラブルのとき

⏱ 読む時間：約4分

📑 目次
  1. PDFが「読めませんでした」
  2. 出場一覧などのボタンが出ない
  3. 記録が見えない・消えた？
  4. 画面がおかしい
レーンちゃんあわてずに、上から順に試してみてね。

PDFが「読めませんでした」

  • スキャンした画像のPDFは読めません（文字が選べるPDFだけ）。
  • URLで読めないときは、PDFをいったん保存してファイルで入れてみてください。
  • 対応を確かめた形式は限られています。読めなかった資料は「📮 不具合・要望を送る」で教えてください（個人情報は書かないでください）。

出場一覧などのボタンが出ない

複数日の大会では「対象日」を選ぶまでボタンが出ません。学校・クラブ名が資料の書き方と合っているかも確かめてください。

記録が見えない・消えた？

  • ログインしていないときの記録は、その端末・そのブラウザの中だけです。別の端末や別のブラウザでは見えません。
  • 古いアドレスで使っていた記録は、新しいアドレスには自動で移りません（「データの保存と書き出し・引っ越し」を見てください）。

画面がおかしい

ページを読み直す（再読み込み）と直ることがあります。それでも直らないときは「📮 不具合・要望を送る」から知らせてください。
